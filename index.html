Svashasan Labs Netrasemi

Strategic Automotive Compute & Software Partnership Strategy

Purpose: Define a mutually beneficial partnership through which Svashasan Labs and Netrasemi can jointly ship Svashasan OS, with Netrasemi receiving a slightly higher commercial benefit while Svashasan retains ownership of its core software and OS intellectual property.

1. Strategic Vision

The strongest structure is not a normal software partnership and not a 50:50 joint venture.

The recommended model is:

Netrasemi becomes the preferred silicon and edge-compute platform for Svashasan OS, while Svashasan becomes Netrasemi’s automotive software and autonomy platform partner.

Netrasemi receives slightly more of the commercial upside because it carries silicon, manufacturing, hardware-validation and supply-chain risk. Svashasan retains ownership of the OS, vehicle software architecture, autonomy IP and its core software stack.

The strategic positioning should be:

Netrasemi Silicon + Svashasan OS = Indigenous Vehicle Intelligence Platform

Instead of selling:

  • Netrasemi → chip
  • Svashasan → OS

the companies jointly sell:

  • Netrasemi reference compute platform
  • Svashasan OS
  • Perception / sensor fusion
  • Vehicle interfaces
  • ADAS / autonomy applications
  • Fleet / OTA infrastructure

to OEMs, fleet operators and mobility companies.

Long-term positioning:

A complete India-built computing and software platform for software-defined vehicles.

2. Why Netrasemi Is Strategically Valuable to Svashasan

Netrasemi positions its SoCs around edge vision, sensor fusion, low-power computation and automotive applications. Its portfolio includes the A2000 at 12 TOPS and a higher-end A4000 roadmap, while its technology stack emphasizes DNN processing, graph-stream architecture, hardware security and scalable compute.

This gives Svashasan an opportunity to move from:

“software running on somebody else’s compute”

to:

“software architected around an Indian silicon platform.”

That distinction matters.

Svashasan can progressively optimize its OS for Netrasemi’s architecture instead of treating the hardware as a generic processor.

3. Why Svashasan Is Strategically Valuable to Netrasemi

A semiconductor company can build excellent silicon and still struggle to achieve OEM adoption.

An OEM does not primarily want to buy:

“12-TOPS SoC.”

The OEM wants:

“Here is a working vehicle compute platform that performs perception, sensor fusion, ADAS, vehicle-control integration, OTA and diagnostics.”

Netrasemi has been working toward reference designs, development platforms, ecosystem partnerships and real-world applications.

Svashasan can become the software/reference-platform layer.

Netrasemi therefore gets:

  • Silicon adoption
  • Design wins
  • OEM engagement
  • SoM demand
  • Evaluation-kit demand
  • Production volumes
  • Differentiation against generic processors
  • Software ecosystem around its silicon
  • Greater hardware platform stickiness

The strongest proposition is:

Svashasan helps turn Netrasemi silicon into a complete automotive computing solution.

5. Commercial Principle: Netrasemi Benefits Slightly More

The partnership should be economically asymmetric but strategically balanced.

Netrasemi should receive a slightly larger share of joint platform revenue because it carries:

  • Silicon development risk
  • Hardware risk
  • Manufacturing risk
  • Supply-chain risk
  • Board/platform development risk

However, Svashasan should not give away its core software IP or its entire software business.

The recommended starting point for joint platform revenue is:

  • Netrasemi: 55–60%
  • Svashasan: 40–45%

A practical opening position is:

Netrasemi 55% / Svashasan 45%

This split should apply only to joint platform revenue, not to everything either company earns independently.

Create separate commercial buckets.

The principle is:

  • Svashasan retains stronger economics on software and fleet/cloud.
  • Custom silicon economics favor Netrasemi significantly.

7. The Core Commercial Flywheel

The real opportunity is not selling one chip.

The goal is to create a platform lock-in loop:

OEM selects Netrasemi platform
          ↓
Svashasan OS deployed
          ↓
OEM integrates sensors and actuators
          ↓
Vehicle applications run on Svashasan OS
          ↓
Future vehicle programs reuse platform
          ↓
More vehicles → more Netrasemi chips
          ↓
More vehicles → more Svashasan OS deployments
          ↓
Recurring revenue for both companies

This creates two mutually reinforcing businesses:

  1. Netrasemi's silicon business
  2. Svashasan's vehicle software business

9. IP Ownership Strategy

This is one of the most important parts of the partnership.

Avoid a blanket clause such as:

“All jointly developed IP is jointly owned.”

That creates unnecessary long-term risk.

Instead divide IP into three categories.

9.1 Background IP

Everything created before the partnership remains owned by the original party.

Netrasemi Background IP

  • SoC architecture
  • Silicon IP
  • NPU
  • Hardware accelerators
  • Chip architecture
  • Hardware security
  • RTL
  • Silicon designs
  • Existing firmware
  • Existing SDK components

Svashasan Background IP

  • Svashasan OS architecture
  • Autonomy architecture
  • Perception software
  • Sensor-fusion software
  • Orchestration
  • Software frameworks
  • OTA architecture
  • Algorithms
  • Proprietary tooling
  • Existing software components

10. Foreground IP

Foreground IP means technology created during the partnership.

Ownership should follow actual contribution and technical boundaries.

Netrasemi-owned

Hardware-specific optimizations and silicon-level inventions.

Svashasan-owned

Vehicle software and OS improvements.

Joint

Only inventions that are genuinely inseparable.

Example:

Netrasemi hardware accelerator + Svashasan software execution model

may produce a jointly licensed technology.

Even then:

Joint ownership should be the exception, not the default.

11. Preferred Silicon Arrangement

Offer Netrasemi:

Preferred Automotive Silicon Partner Status

Do not immediately grant unlimited exclusivity.

Recommended structure:

Netrasemi becomes Svashasan’s preferred silicon partner for designated automotive compute configurations for an initial 3-year period.

Svashasan should retain the ability to support other silicon platforms when required by OEMs or technical programs.

Potential platforms may eventually include:

  • Netrasemi
  • NVIDIA
  • Qualcomm
  • Renesas
  • Texas Instruments
  • Other automotive silicon providers

The strategic objective is:

Preferred relationship, not dangerous permanent dependency.

15. Initial Use of Netrasemi A2000

Netrasemi describes the A2000 as a mid-range 12-TOPS Edge AI SoC with applications including complex vision workloads and sensor fusion.

This makes it a potentially useful starting point for the first development platform, subject to actual:

  • Automotive interface availability
  • Thermal requirements
  • Safety requirements
  • Hardware validation

  • Production qualification
  • Sensor throughput requirements

Do not claim that the A2000 is automatically a production-ready autonomous-driving processor.

The appropriate positioning is:

Use A2000 as the initial development and validation platform.

Then jointly define requirements for future automotive-focused silicon.

24. OEM Account Ownership

Do not allow one partner to control all OEM relationships.

Recommended principle:

Jointly sourced OEM opportunity

Joint account.

Svashasan-originated OEM

Svashasan retains account rights, subject to agreed commercial participation by Netrasemi.

Netrasemi-originated OEM

Netrasemi retains account rights, subject to agreed Svashasan participation.

This prevents either party from eventually bypassing the other.

25. Non-Circumvention

The agreement should contain strong non-circumvention protections.

Neither party should be allowed to use the other’s:

  • Technology
  • Customer introductions
  • Architecture
  • Proprietary materials
  • Commercial intelligence
  • Confidential technical information

to directly bypass the other for a defined joint program.

For example:

  • Netrasemi should not take Svashasan’s proprietary architecture to another software provider.
  • Svashasan should not take proprietary Netrasemi silicon information to another chip supplier.

34. What Not to Do

Do not create a 50/50 JV immediately

There is too much complexity before product-market validation.

Do not make Svashasan exclusive to Netrasemi globally

Svashasan needs silicon flexibility for OEM requirements.

Do not transfer Svashasan OS IP

License it.

Do not promise Level 4 autonomy in the first agreement

Start with a concrete automotive compute and ADAS platform.

Do not build everything yourselves

Use Netrasemi’s existing hardware and SDK where appropriate.

Do not accept unlimited custom engineering for free

Every significant OEM customization should have a paid commercial scope.

39. Overall Strategic Verdict

This is potentially a very strong partnership and should be pursued if technical and commercial diligence validates the underlying hardware, SDK, automotive qualification path and execution capabilities.

The partnership should be:

Asymmetric economically but balanced strategically.

Netrasemi should receive the slightly larger commercial share because it carries semiconductor development, hardware and manufacturing risk.

Svashasan should retain:

  • 100% ownership of its core OS
  • 100% ownership of pre-existing software IP
  • Core autonomy/perception IP
  • Software licensing economics
  • Fleet/cloud economics
  • The ability to support other silicon when necessary

The biggest opportunity is not the first joint demonstration.

The bigger opportunity is establishing a loop where:

Netrasemi silicon becomes optimized for Svashasan workloads, while Svashasan OS becomes optimized for Netrasemi silicon.

Then the combined reference platform can be taken to OEMs.

The partnership should therefore be sold internally at Svashasan as:

“We are not becoming dependent on Netrasemi. We are making Netrasemi our first strategic silicon platform while turning the relationship into an OEM-scale hardware/software ecosystem.”

And to Netrasemi:

“You don't just get a software customer. You get an automotive software platform around your silicon.”

That is the version of the deal where Netrasemi wins slightly more today, while both companies have the potential to win substantially more if the OEM platform succeeds.
